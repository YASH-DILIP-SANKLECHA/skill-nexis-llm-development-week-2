# Assignment 2 — Language Model Training

## Objective
Build a character-level bigram language model using a small openly reusable text dataset.

## Tasks covered
1. Prepare and inspect the text dataset.
2. Build a character vocabulary.
3. Implement text encoding and decoding.
4. Create separate training and validation data.
5. Train a bigram language model and record training/validation loss.
6. Compare generated samples before and after training.

## Files
- `language_model_training.ipynb`: complete implementation, explanations, generated samples, and evaluation.
- `dataset.txt`: text used by the notebook.
- `training_results.csv`: generated by the notebook when training runs.

## Run
Install dependencies with `python -m pip install torch jupyter`. Open the notebook in VS Code and run all cells from top to bottom.
