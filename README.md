# Skill Nexis — LLM Development Week 2

This repository contains Assignment 2: Language Model Training.

## Assignment 2
The notebook prepares a text dataset, builds a character vocabulary, implements encoding and decoding, creates training and validation splits, trains a bigram language model, records losses, and compares generated samples before and after training.

## Structure
- `Assignment_2_Language_Model_Training/language_model_training.ipynb` — complete assignment notebook
- `Assignment_2_Language_Model_Training/dataset.txt` — original educational text dataset
- `Assignment_2_Language_Model_Training/training_results.csv` — generated loss history
- `Assignment_2_Language_Model_Training/README.md` — assignment instructions

## Requirements
Python 3.10 or newer, PyTorch, and Jupyter.

Install with `python -m pip install torch jupyter`, then open the notebook in VS Code and run all cells from top to bottom.
