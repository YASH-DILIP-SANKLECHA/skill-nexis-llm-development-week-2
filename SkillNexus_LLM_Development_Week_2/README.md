# SkillNexus — LLM Development Week 2

This archive contains **Mini Project 2: Character-Level Text Generator**.

Open `Mini_Project_2_Character_Level_Text_Generator/character_level_text_generator.ipynb` in VS Code and run all cells in order.

Install requirements with:
`python -m pip install torch matplotlib jupyter`

The notebook trains a character-level bigram model, records training and validation losses, saves a model checkpoint, and creates ten generated samples. The included original educational dataset is dedicated to the public domain under CC0 1.0.
